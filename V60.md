# Klasévia V60 — Compétences & progression

V60 part de la base React V59 et ajoute un pont UI entre les conversations et le moteur de compétences Supabase.

## Ajouts
- chargement des compétences depuis `public.skills`;
- affichage de la maîtrise/tentatives depuis `skill_progress`;
- sélection manuelle d'une compétence pour la conversation;
- détection heuristique locale pour proposer une compétence à partir du thème/sujet;
- stockage de `context.skill_id` dans `student_conversations`;
- conservation des API IA existantes;
- aucune clé secrète dans le frontend;
- aucune modification destructive des données pédagogiques.

## Vérification
La base Supabase possède déjà les migrations V59 `student_conversation_history`, `conversation_history_privileges` et `conversation_context`, et la table `student_conversations` dispose de RLS.

Le build Vite n'a pas pu être exécuté dans l'environnement de génération faute de terminer `npm install` dans le délai disponible. Le code a été généré à partir du projet V59 fourni et doit être vérifié par `npm install && npm run build` dans GitHub/Vercel avant déploiement.

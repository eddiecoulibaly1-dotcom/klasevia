# Klasévia V61 — Tuteur pédagogique guidé

V61 fait évoluer le tuteur IA de la simple réponse vers un parcours pédagogique court et actionnable.

## Nouveautés
- Nouveau mode **Apprendre avec guidage + vérification**.
- Structure guidée : objectif → explication → à retenir → question de vérification → étape suivante.
- La compétence suivie et la maîtrise connue sont transmises au tuteur sans exposer les métriques internes.
- Raccourcis après les réponses : vérification de compréhension et exercice ciblé.
- Aucun nouveau schéma SQL.

## Déploiement
1. Remplacer le projet GitHub par cette version.
2. Vercel redéploie.
3. Vérifier `GEMINI_API_KEY` côté Vercel.
4. Attendre le statut **Ready** puis tester le mode guidé.

## Vérification
Le build npm n'est pas exécuté dans cet environnement. Le build Vercel doit être vérifié avant mise en ligne publique.
